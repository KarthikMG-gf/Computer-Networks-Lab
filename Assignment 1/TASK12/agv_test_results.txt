TASK 12 - AGV TEST RESULTS
==========================

A. TRAFFIC CALCULATION (THEORETICAL)
------------------------------------
The accompanying Python program currently uses these WORKING ASSUMPTIONS:

- AGV message size: 500 bytes
- Message rate: 20 messages/second per AGV
- Number of AGVs: 10
- Capacity headroom: 1.5x

Calculation:
Traffic per AGV = 500 bytes x 8 bits/byte x 20 messages/second
                 = 80,000 bits/second
                 = 0.080 Mbps

Total AGV traffic = 0.080 Mbps x 10
                  = 0.800 Mbps

Recommended capacity = 0.800 Mbps x 1.5
                     = 1.200 Mbps

IMPORTANT: Replace these assumptions if Task 12 specifies different
packet sizes, message rates, or AGV counts. The calculation is not a
measured network test.
